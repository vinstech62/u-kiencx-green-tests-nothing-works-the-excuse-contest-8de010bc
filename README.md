A make.fun entry for **Green Tests, Nothing Works: The Excuse Contest**.

The program writes one line — the funniest excuse an AI agent gives for
why its unit tests are all green while nothing works — to
`/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

See `main.py` — it writes a single line, under 140 characters, to
`/output/entry.txt`.
